# River 广告平台数据库表关系

## 业务概述

River 是一个广告联盟管理平台，核心业务流程：
1. 从广告联盟（Admitad, CJ, ShareASale 等）拉取商家、Offer、优惠券数据
2. 通过 SEO（deals.ecommica.com）和 Media Buy（Google Ads）获取流量
3. 用户点击追踪链接产生转化，平台获得佣金


## 模块说明

| 模块 | 表前缀 | 说明 |
|------|--------|------|
| **Affiliate** | `river_affiliate_` | 联盟网络、商家、Offer、分类 |
| **Coupon** | `river_coupon_` | 优惠券、促销活动 |
| **Blog** | `river_blog_` | SEO 博客文章、作者、标签 |
| **Campaign** | `river_campaign_` | Media Buy 广告系列管理 |
| **Tracking** | `river_tracking_` | 点击追踪、转化记录 |
| **Stats** | `river_stats_` | 统计报表 |

## 表清单

### Affiliate 模块
- `river_affiliate_network` - 联盟网络（Admitad, CJ 等）
- `river_affiliate_network_credential` - 联盟 API 凭证
- `river_affiliate_category` - 商家/Offer 分类
- `river_affiliate_merchant` - 商家
- `river_affiliate_offer` - 广告 Offer
- `river_affiliate_postback_secret` - Postback 密钥

### Coupon 模块
- `river_coupon_coupon` - 优惠码
- `river_coupon_deal` - 促销活动

### Blog 模块
- `river_blog_post` - 博客文章
- `river_blog_author` - 作者
- `river_blog_tag` - 标签
- `river_blog_post_tag` - 文章-标签关联
- `river_blog_post_offer` - 文章-Offer 关联

### Campaign 模块
- `river_campaign_traffic_source` - 流量来源
- `river_campaign_campaign` - 营销活动
- `river_campaign_ad_group` - 广告组
- `river_campaign_landing_page` - 落地页
- `river_campaign_cost_record` - 成本记录
- `river_campaign_currency` - 货币
- `river_campaign_fx_rate` - 汇率

### Tracking 模块
- `river_tracking_link` - 追踪链接
- `river_tracking_click` - 点击记录（按月分表）
- `river_tracking_conversion` - 转化记录
- `river_tracking_attribution` - 归因记录
- `river_tracking_unattributed_conversion` - 未归因转化

### Stats 模块
- `river_stats_hourly` - 小时统计
- `river_stats_daily` - 每日统计
